# Contributing

This repository welcomes fixes to guides, new prompt examples, and corrections to the public demo. Changes to the SDK implementation are handled separately.

- Describe the reader’s problem and how the change resolves it.
- Write prompts for a compatible agent rather than a specific vendor unless the example is explicitly host-specific.
- Distinguish what a host actually ran from what a package is expected to support.
- Use synthetic examples and omit project names, personal paths, credentials, and private logs.
- Check Markdown links, image alt text, and file paths before opening a pull request.

For questions and documentation problems, use the [issue forms](https://github.com/mikegorelikoff/unhooked-sdk/issues/new/choose).
