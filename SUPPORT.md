# Support

- Start with the [quickstart](docs/Quickstart.md) and [example prompts](docs/Examples.md).
- Report a public documentation problem or propose a new example through [Issues](https://github.com/mikegorelikoff/unhooked-sdk/issues/new/choose).
- For SDK access or installation issues that depend on private code, contact the person or team that provided your release. Share only sanitized excerpts.
- Use [Security](SECURITY.md) for confidential security reports.
