# Reporting a security concern

This repository publishes documentation, examples, and media. Do not open a public issue containing a suspected vulnerability, personal information, or credentials.

Report a concern with this repository privately using [GitHub vulnerability reporting](https://github.com/mikegorelikoff/unhooked-sdk/security/advisories/new). Explain what is affected and how to reproduce the behavior with sanitized data. For concerns with a separately distributed SDK release, use the private support channel provided with that release.
